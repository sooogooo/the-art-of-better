# 框架规范：积极斯多葛主义心理学

## 1. 名称与身份

- **中文名**：积极斯多葛主义心理学。
- **英文名**：*Positive Stoic Psychology*。
- **身份**：本书作者提出的解释和写作框架，不是已确立的心理学分支、临床方法、诊断体系或效果已被验证的干预。
- **书中简称**：积极斯多葛框架。

“积极”不是永远乐观，也不是把不满意、疼痛、后悔或愤怒视为错误；它指向一种建设性姿态：允许改善愿望存在，同时拒绝把人的尊严外包给外貌结果、消费结果或他人的认可。

## 2. 与历史斯多葛主义的关系

本书借用古典斯多葛传统中关于判断、选择、德性、共同体和可控性的思想资源，尤其是对“把精力放在自己的判断与行动上”的强调。它不宣称对斯多葛文本作唯一正确的学术解释，也不把古典哲学简化成“不要在乎外貌”或“忍受一切”。历史文本的阐释问题，与本书的现代消费心理学主张分开标注。

## 3. 五个构件

### 3.1 可控梯度

不用生硬的二分法，而用三层梯度阅读改善选择：

1. **我负责的选择**：是否咨询、问什么、是否付费、何时暂停、是否寻求第二意见。
2. **我可以影响的条件**：信息质量、沟通质量、支持系统、恢复安排和预算边界。
3. **我无法占有的结果**：他人的评价、社会审美、身体的全部反应、结果的完全可预测性。

它的作用不是降低期待，而是把期待放回可负责的尺度。

### 3.2 改善与价值脱钩

人可以希望更年轻、精致、舒适、得体或更有掌控感；但“我希望改变某一处”不等于“我作为一个人必须先被修好”。改善是选择，人的基本价值不是项目回报率。

### 3.3 认识上的克制

在有限证据、营销放大和不确定结果之间，框架要求把“我被说服了”与“我已经知道了”分开。它鼓励追问证据、利益冲突、替代方案、恢复时间和退出成本，而非要求读者成为医学专家。

### 3.4 时间上的善待

冲动不总是非理性，但高压力、强比较和限时促销会缩短考虑时间。框架重视延迟、复盘、恢复期支持和允许改变主意；“暂不决定”是一种完整的决定。

### 3.5 关系中的尊严

审美愿望常在伴侣、家人、同事、平台与医疗机构之间形成。框架既不把所有愿望归咎于外界，也不把社会压力说成个人脆弱；它要求在关系中维护拒绝权、解释权和不被羞辱的权利。

## 4. 允许的解释与禁止的外推

| 可以这样说 | 不可以这样说 |
| --- | --- |
| “本书用积极斯多葛框架来解释此处的决策压力。” | “积极斯多葛主义心理学证明这样做能改善心理健康。” |
| “这个问题可帮助你区分可控的准备与不可控的评价。” | “回答这组问题即可判断你是否适合医美。” |
| “这是作者关于改善伦理的立场。” | “这是临床共识或医学建议。” |
| “该框架与斯多葛文本存在启发性联系。” | “古典斯多葛主义要求或禁止某种医美项目。” |

## 5. 书稿中的证据标签

每一章在题注中标明“**框架标签：积极斯多葛框架（原创解释框架）**”。所有可检验陈述按以下规则标注并在证据台账中登记：

- **[事实 F-xxx]**：有可追溯来源、具体定位和适用范围的描述。
- **[推断 I-xxx]**：从一个或多个事实出发的有限解释；必须写明不是因果证明或个体判断。
- **[立场 N-xxx]**：作者的伦理、审美或消费立场；不以“研究证明”包装。

不能被适当归类的句子不进入正式书稿。

## 6. 读者边界

框架适用于成年读者对医美、服饰、健身、学习、居住、职业形象和其他改善型消费的反思。它不替代医生、心理治疗师、精神科医生、法律专业人员或监管机关的专业判断；若外貌困扰造成显著痛苦、回避、强迫性检查或安全风险，应寻求合格的心理健康和医疗支持。
